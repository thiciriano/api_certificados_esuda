## 8. Persistência
Os registros criados nesta demonstração (categoria, evento, inscrição e
certificado) foram recuperados por GET em requisições HTTPS separadas.
O banco é PostgreSQL persistente no Render, configurado em render.yaml;
o boot roda create_all() sem drop_all(), preservando os dados entre deploys.
